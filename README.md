# eiken_study
英語検定の勉強をすることができます。
まだ開発中なので、欲しい機能などがあれば本人まで。

## v1.6の変更点
- **履歴の永続化**：学習履歴と単語ごとの記録を、ブラウザのlocalStorage（キー `eiken_study_v1`）に保存します。リロードしても履歴テーブルとグラフが残ります。
- **間隔反復（簡易SM-2）**：正解すると次回までの間隔が 1日 → 3日 → 7日 → 14日 → 30日と伸びます。不正解・時間切れの場合は1日に戻ります。
- **今日の復習**：期限（due）が来た単語を、期限が古い順・間違えた回数が多い順に出題するモードを追加しました。期限切れの件数はバッジで表示します。期限切れがなければ、そのセッションで間違えた問題の復習に切り替わります。
- **次回復習日**：履歴テーブルに「次回復習」列を追加し、単語ごとの次回復習日を表示します。
- **履歴の復元**：「履歴をCSVから復元」ボタンで、エクスポートした履歴CSVを読み込んで履歴を復旧できます（現在の履歴を置き換えます。単語別記録は履歴CSVに含まれないため復元されません）。
- **保存データの消去**：「保存データを消去」ボタンで、localStorageの保存データとメモリ上の履歴・単語別記録をすべて消去します。「履歴をリセット」も同じく保存データまで消去します。

```json
  "words": {

  }
}
```
