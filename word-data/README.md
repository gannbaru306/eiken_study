# 単語データ

英検学習アプリで使う単語データです。アプリの「ファイルを選択」からCSVを読み込んで使います。

## 形式

`level,word,meaning` のCSVです。

- `level`：級（`5`、`4`、`3`、`準2`、`2`、`準1`、`1`）
- `word`：英単語（小文字1語）
- `meaning`：日本語の意味
